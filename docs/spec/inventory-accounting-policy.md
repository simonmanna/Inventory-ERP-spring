Status: **draft for owner sign-off** (IPR Phase 2, stream C, branch `fix/ipr-2`, 2026-11-27). Each row states what
the code does on this branch, so the owner can approve it or ask for a change. A row is closed when the approver and
date are filled in. Settings are named so a decision can change without code where the column says so.
